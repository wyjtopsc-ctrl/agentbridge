# Code of Conduct

This project follows the spirit of the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep technical disagreement about the work rather than the
person. Harassment, discrimination and disclosure of private information are not acceptable.

Reports can be sent to the maintainer through the contact method on the GitHub profile. Reports are
reviewed confidentially. Maintainers may remove comments, close issues, or block accounts when
behaviour violates this code.
