- 0.9.4 不改变 evidence-pack v0.2 的字段/格式，属于试点前安全加固补丁；冻结基线仍是 0.9.3。
- 冻结后影响字段、验证语义或兼容性的修改进入新协议版本，不覆盖冻结材料（见 `frozen/evidence-pack-v0.2/`）。
